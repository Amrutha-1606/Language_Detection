# Language Detection

## Description

Language Detection is a Natural Language Processing application that automatically identifies the language of a given text.

The application uses the Langdetect Python library to detect the language.

## Technology Used

- Python
- Langdetect
- Natural Language Processing

## Languages Supported

The application can identify many languages, including:

- English
- Telugu
- Hindi
- Tamil
- Kannada
- Malayalam
- French
- Spanish
- German
- Italian
- Portuguese
- Arabic
- Russian
- Japanese
- Korean
- Chinese

## Requirements

Python 3.x

## Installation

Install the required library:

pip install langdetect

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install Langdetect:

pip install langdetect

4. Run the program:

python app.py

5. Enter some text.
6. The application displays the detected language.
